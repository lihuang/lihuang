# 股价市值小程序

一个微信小程序，用来查看指定股票/公司的**实时股价**和**总市值**，支持 A 股（沪/深/北）、港股、美股。

## 功能

- **搜索**：输入公司名称、股票代码或拼音（如 `茅台`、`00700`、`AAPL`、`gzmt`）
- **自选列表**：首页展示现价、涨跌幅、总市值；下拉刷新，长按删除
- **详情页**：现价、涨跌额/涨跌幅、总市值、今开/昨收/最高/最低，近 60 个交易日收盘价走势图；页面打开期间每 10 秒自动刷新
- **分享**：可将某只股票的详情页分享给好友

市值按币种显示，并自动换算为“万亿 / 亿 / 万”，例如 `2.14万亿元`、`3,456.79亿港元`。

## 目录结构

```
stock-miniprogram/
├── app.js / app.json / app.wxss   全局配置（默认自选股票在 app.js 中修改）
├── pages/index/                   首页：搜索 + 自选列表
├── pages/detail/                  详情页：股价、市值、走势图
├── utils/quote.js                 行情/搜索/K 线数据解析与格式化（纯函数）
├── utils/api.js                   网络请求
├── utils/storage.js               自选列表与名称缓存
└── tests/quote.test.js            解析逻辑单元测试
```

## 运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，导入 `stock-miniprogram` 目录。
2. 在 `project.config.json` 中把 `appid` 换成你自己的小程序 AppID（或使用测试号）。
3. 本地调试时可在开发者工具中勾选“不校验合法域名”。正式发布前，需要在小程序后台
   「开发管理 → 开发设置 → 服务器域名 → request 合法域名」中添加：
   - `https://qt.gtimg.cn`（实时行情）
   - `https://smartbox.gtimg.cn`（股票搜索）
   - `https://web.ifzq.gtimg.cn`（日 K 线）

修改默认展示的股票：编辑 `app.js` 中的 `defaultCodes`，代码格式为市场前缀 + 代码，例如 `sh600519`、`sz000001`、`hk00700`、`usAAPL`。

## 测试

```bash
node tests/quote.test.js
```

## 说明与限制

- 行情数据来自腾讯财经公开接口，非官方 API，字段可能变动；所有解析集中在 `utils/quote.js`，接口变动时只需改这里。
- 实时行情接口返回 GBK 编码，小程序内无法解码中文名称，因此股票名称取自搜索接口（Unicode 转义，可正常显示）并缓存在本地；未搜索过的股票会先显示代码。
- 总市值取行情接口第 45 个字段（单位：亿），缺失时退回第 44 个字段。
- 走势图为附加信息，K 线接口无数据时（部分美股代码）会自动隐藏。
- 行情可能有延迟，仅供参考，不构成投资建议。
